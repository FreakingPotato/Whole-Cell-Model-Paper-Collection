## Method

For each evidence point, the QA driver creates `/tmp/qa/qa_<id>.html` - a copy of `graph.html` with an injected `<script>` that:

1. Sets `window.location.hash = "hybrid"` after `load`.
2. After 250 ms, finds `[data-evidence-id="<id>"]` and calls `.click()`.
3. After another 300 ms, snapshots the modal DOM (open flag, presence of `<img>` / `<iframe>` / `.modal-pdf-fallback`, caption, action links) into a hidden `<pre id="__qa_state__">` element.
4. For the Esc test, dispatches a synthetic `Escape` `keydown` and resnapshots `data-open`.

The harness file is then loaded in `chrome --headless --dump-dom` to read `__qa_state__`, and in `chrome --headless --screenshot` for the visual artifacts. Evidence PNGs are referenced by `evidence/<id>.png`, which the symlink `/tmp/qa/evidence` resolves to `graphify-out/evidence/`.
